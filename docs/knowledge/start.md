# Start learning IT operations

IT operations means keeping the computers, applications, and information an organization depends on available and usable. Start with one question. You can stop after any section.

## Level 1: Everyday explanation

An application is a program that helps someone do a task. A server is a computer or program providing a service to other programs. A network connects devices. A database organizes information so applications can retrieve and change it.

For example, a library checkout application needs a record of books, a way to identify staff, and a way to recover records after failure. These needs also appear in schools, hospitals, businesses, and banks.

## Level 2: Operational responsibilities

Decide who owns each service, who may use it, how failures will be noticed, and how information will be recovered. Define success before buying tools: what data loss and downtime can the organization tolerate?
